# Asset Sources

The current built-in assets are generated locally by `tools/assets/generate-builtins.mjs`.

Generated assets:

- Basic debug textures: checkerboard, UV grid, white, black, gray, flat normal, blue noise.
- Basic mesh assets: cube, plane, sphere, material test spheres.
- Scene presets: shadow, PBR, postprocess, and ray tracing starter scenes.

No third-party runtime assets are included yet.
