Start

Use the top Lab selector to run built-in labs or user-composed experiments. Use Blueprint to edit reusable render graph logic and WGSL. Use Lab to compose a scene, a blueprint, and per-object material instances into a runnable experiment.

Where To Code

Most rendering experiments should be authored in the web Blueprint editor. User files are stored in user-labs/blueprints/<blueprint-id>/ and user-labs/experiments/<lab-id>/. Implement a traditional Lab only when you need direct WebGPU control beyond the graph system.

Blueprint

A Blueprint defines graph resources, render passes, explicit bindings, and WGSL shader files. It does not choose the final scene or object material assignment. 

user-labs/blueprints/<blueprint-id>/blueprint.json
user-labs/blueprints/<blueprint-id>/shaders/main.wgsl

Lab Composer

Lab Composer creates runnable experiments by selecting a classic scene, selecting a Blueprint, creating material instances, and assigning those material instances to scene objects.

Material instances share the same mesh-pass shader in v1. They vary material uniforms and built-in texture slots such as baseColorTexture and normalTexture. 

user-labs/experiments/<lab-id>/lab.json

Bindings

Bindings are explicit and close to WebGPU. Material texture sources use the per-object material.* namespace.

bindings: [
  uniform("frame", { group: 0, binding: 0, source: "frame" }),
  uniform("params", { group: 0, binding: 1, source: "params" }),
  uniform("object", { group: 1, binding: 0, source: "object" }),
  uniform("material", { group: 1, binding: 1, source: "material" }),
  texture("baseColorTexture", { group: 1, binding: 2, source: "material.baseColorTexture" }),
  sampler("materialSampler", { group: 1, binding: 3, source: "material.sampler" }),
]

WGSL

The default mesh vertex layout is position / normal / uv. Mesh pass entry points are vertexMain and fragmentMain.

@group(0) @binding(0) var<uniform> frame: FrameUniforms;
@group(0) @binding(1) var<uniform> params: ParamsUniforms;
@group(1) @binding(0) var<uniform> object: ObjectUniforms;
@group(1) @binding(1) var<uniform> material: MaterialUniforms;
@group(1) @binding(2) var baseColorTexture: texture_2d<f32>;
@group(1) @binding(3) var materialSampler: sampler;
