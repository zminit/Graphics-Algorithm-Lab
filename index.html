实验平台使用指南

开始实验

顶部 Lab 选择框用于切换实验。右侧面板显示当前实验的参数、Debug View 和贴图预览。 底部 Runtime Log 用来查看 WebGPU、shader 编译和运行时错误。

学习算法时优先使用 Pipeline Basic Mesh 这种声明式实验： 平台负责相机、场景、mesh 上传、pipeline 创建和 draw loop，你主要改实验声明和 WGSL。

资源文件在哪里

运行时静态资源统一放在 public/assets/，浏览器中直接用以 /assets/ 开头的路径访问。

模型public/assets/builtin/models/ 纹理public/assets/builtin/textures/ 场景public/assets/builtin/scenes/ HDRpublic/assets/builtin/hdr/ 资源索引src/core/assets/BuiltinAssets.ts

内置基础资源由 tools/assets/generate-builtins.mjs 生成。 需要重新生成基础模型、调试纹理和场景 preset 时运行： 

npm run assets:generate

算法代码要在哪里写

新算法推荐新建 src/labs/<lab-name>/<Name>Lab.ts， 然后在 src/labs/registerLabs.ts 注册。shader 文件放在 public/shaders/ 下。

当前最小示例：

Lab 声明src/labs/pipeline-basic-mesh/PipelineBasicMeshLab.ts WGSLpublic/shaders/pipeline/basic-mesh.wgsl 底层接口src/core/pipeline/

如果算法必须完全控制 WebGPU，例如自定义多 render target、compute pass 或特殊资源生命周期， 可以直接实现传统 Lab 接口；如果只是改渲染方程、顶点处理、光照或材质计算，优先用 Pipeline Lab。

Pipeline Lab 最小写法

这个写法把工程样板压到最低，同时保留手写 shader 和显式资源绑定的学习空间。

export const MyLab = definePipelineLab({
  id: "my-lab",
  name: "My Lab",
  scene: BuiltinAssets.scenes.shadowTest,
  params: {
    ambient: float(0.2, { min: 0, max: 1, step: 0.01 }),
  },
  passes: [
    meshPass({
      name: "Main",
      shader: "/shaders/my-lab/main.wgsl",
      bindings: "default",
      color: "screen",
      depth: "auto",
    }),
  ],
});

Binding 接口怎么用

bindings: "default" 会使用平台默认 uniform 布局。 想更接近原生 WebGPU 时，可以显式声明 group、binding 和资源来源： 

bindings: [
  uniform("frame", { group: 0, binding: 0, source: "frame" }),
  uniform("params", { group: 0, binding: 1, source: "params" }),
  uniform("object", { group: 1, binding: 0, source: "object" }),
  uniform("material", { group: 1, binding: 1, source: "material" }),
]

当前 v1 已支持自定义 uniform binding。texture、sampler、fullscreen pass、render target alias 和 compute pass 会作为下一批 Pipeline Lab 能力继续扩展。

WGSL 约定

默认 mesh 顶点布局是 position / normal / uv，shader 入口固定为 vertexMain 和 fragmentMain。

@group(0) @binding(0) var<uniform> frame: FrameUniforms;
@group(0) @binding(1) var<uniform> params: ParamsUniforms;
@group(1) @binding(0) var<uniform> object: ObjectUniforms;
@group(1) @binding(1) var<uniform> material: MaterialUniforms;

frame 提供相机矩阵、画布尺寸和时间； params 来自右侧 GUI； object 提供模型矩阵和 MVP； material 提供基础材质参数。

调试与日志

Lab 可以通过 ctx.gui.add(...) 注册右侧参数，通过 ctx.debug.addTexture(...) 注册 Debug View 纹理。运行时报错会进入底部 Runtime Log，右上角状态只展示简短摘要。

如果遇到 shader 编译失败，先展开 Runtime Log 复制完整错误，再检查 WGSL 的 binding、入口函数和 uniform 结构体是否与 Lab 声明一致。
